# ABC 🎮

> 和孩子一起做的第一个 Godot 游戏（名字暂定，想好了就改掉它！）

## 怎么打开这个项目

1. 下载并安装 [Godot 4](https://godotengine.org/download)（选 **标准版 Standard**，不用 .NET 版）
2. 打开 Godot，点 **导入（Import）**
3. 选择本文件夹里的 `project.godot` 文件
4. 点 **编辑（Edit）**，进入游戏编辑器

## 文件夹导览

| 文件夹 | 放什么 | 给孩子的一句话 |
|---|---|---|
| `player/` | 玩家角色 | "你操控的小英雄住在这里" |
| `enemies/` | 敌人 | "坏蛋们住在这里" |
| `levels/` | 关卡 | "每一关是这里的一张地图" |
| `ui/` | 界面 | "开始按钮、分数显示住在这里" |
| `assets/art/` | 图片素材 | "你画的画拍成照片放这里" |
| `assets/audio/` | 声音 | "音效和背景音乐放这里" |
| `assets/fonts/` | 字体 | "游戏里用的漂亮文字" |
| `docs/` | 设计笔记 | "我们的游戏点子本" |
| `addons/` | 插件 | "以后装扩展用的，现在空着" |

## 一起干活的小约定

- 场景文件（`.tscn`）和它的脚本（`.gd`）放在同一个功能文件夹里
- 文件名用英文小写 + 下划线，比如 `player.tscn`、`green_slime.gd`
- 孩子画的素材拍成照片，起个英文文件名放进 `assets/art/`，比如 `cat_drawing.png`

## 运行首版

工程已有可玩主场景：导入 `project.godot` 后按 **F5**。

- 点击守兵卡，再点击棋盘放置；顶部出生行不能放兵。
- 点击“开始守卷”，共 10 波；漏过一个敌人即失败。
- 初始 100 墨滴，每 10 秒自动增加 50 滴。
- 十种守兵、七种敌人；第 8 波起有飞行敌人“翼”，需电或闪防空，第 9 波起有高生命敌人“玄”。
- **P** 暂停/继续，**Esc / 右键**取消选择；按钮可以重新开始。
- 完整规则和浏览器导出步骤见 [首版规则与试玩说明](docs/specs/first_playable.md)。

## 代码导览

| 文件 | 用途 |
|---|---|
| `levels/main.tscn` / `main.gd` | 主场景、棋盘绘制、卡牌和操作界面 |
| `levels/battle.gd` | 战斗、墨滴、波次、胜负规则 |
| `player/guard_data.gd` | 十种守兵的数值 |
| `enemies/enemy_data.gd` | 七种敌人的数值 |
| `export_presets.cfg` | 单线程 Web 导出预设 |
| `assets/fonts/` | 开源中文字体及许可证 |

## 和孩子一起试玩

每次先观察一个问题，再改一个数值，例如“盾能挡多久”“雷放在哪里才来得及准备”。原型波次和准备时间是试用值，欢迎由孩子调整。
